## ✨ Возможности проекта

* 🔍 **Универсальный поиск вакансий**: поиск по любой специальности, ключевым словам, локации и опыту через гибридный клиент (официальный API + Web-скрапинг fallback).
* 📊 **Локальная база данных в Excel (`data/vacancies.xlsx`)**: автосохранение всех вакансий, статусов (`NEW`, `ANALYZED`, `APPLIED`, `INVITED`, `SKIPPED`), зарплат, сгенерированных писем и дедупликация записей.
* 🧠 **AI-скоринг и сопроводительные письма**: расчет процента соответствия (**Match Score 0–100%**) на основе вашего резюме, выделение сильных/слабых сторон и генерация индивидуального письма под каждую вакансию.
* 🚀 **Официальные отклики**: отправка откликов через `api.hh.ru/negotiations` за ~200 мс без открытия браузера.
* 🎭 **Playwright + AI для сложных вакансий**: автоматическое прохождение опросников и тестов работодателя в headless-браузере.
* 🌐 **Web Dashboard в браузере**: локальный веб-интерфейс на FastAPI + Tailwind CSS со сводкой метрик, таблицей вакансий, редактором писем и кнопками действий.
* 📱 **Интерактивный Telegram-бот (`aiogram 3`)**: карточки вакансий в чате с инлайн-кнопками «Откликнуться» / «Пропустить», выбор резюме и мгновенные уведомления.
* ⏰ **Фоновый планировщик (`APScheduler`)**: периодический автопоиск вакансий (каждые 30 мин) и трекинг приглашений от HR (каждые 10 мин).

## 🚀 Быстрый старт с нуля

### Шаг 1. Настройка окружения и файла `.env`

1. Убедитесь, что виртуальное окружение активировано и зависимости установлены:
   ```bash
   python3 -m venv venv
   source venv/bin/activate
   pip install -r requirements.txt
   playwright install chromium
   ```

2. Откройте файл `.env` в корне проекта и проверьте ключи:
   ```env
   # HeadHunter API (из вашего кабинета на dev.hh.ru)
   HH_CLIENT_ID=ВАШ_CLIENT_ID
   HH_CLIENT_SECRET=ВАШ_CLIENT_SECRET
   HH_REDIRECT_URI=https://hh.ru
   HH_USER_AGENT=JobAgent/1.0 (ваш_email@gmail.com)

   # Telegram Bot (токен от @BotFather и ваш Chat ID от @userinfobot)
   TELEGRAM_BOT_TOKEN=8813858406:AAGi5T2tsCUJ4S3RiFzVggnNEMvuG_eZgYQ
   TELEGRAM_CHAT_ID=302327777

   # LLM (опционально для внешних моделей OpenAI / DeepSeek / Ollama)
   OPENAI_API_KEY=
   OPENAI_MODEL=gpt-4o
   ```

### Шаг 2. Настройка вашего резюме

Откройте файл `data/my_resume.txt` и вставьте актуальное описание вашего опыта, навыков и стека. 

> Агент автоматически парсит ключевые навыки из этого файла для сопоставления с требованиями вакансий и составления писем.

---

### Шаг 3. Авторизация в HeadHunter (OAuth 2.0)

Авторизация выполняется **1 раз** (токены сохраняются и обновляются автоматически):

1. Запустите в терминале:
   ```bash
   ./venv/bin/python main.py auth
   ```
2. Скрипт выведет ссылку авторизации вида:
   ```text
   https://hh.ru/oauth/authorize?response_type=code&client_id=...&redirect_uri=https://hh.ru
   ```
3. Откройте ссылку в браузере под вашим аккаунтом HH.ru и нажмите **«Разрешить»**.
4. Вас перенаправит на `https://hh.ru/?code=XXXXXXXXXXXX`. Скопируйте значение параметра `code` из адресной строки.
5. Вставьте скопированный код в консоль и нажмите Enter.

## 🌐 Управление через Web Dashboard

Откройте в браузере **`http://localhost:8000`**:

1. **Верхняя панель:**
   * Выпадающий список ваших резюме на HeadHunter (выбранное резюме используется для откликов).
   * Кнопка **«Excel»** — скачивание актуальной базы `vacancies.xlsx`.
   * Индикатор статуса авторизации в HH.ru.
2. **KPI-карточки:** общее число вакансий, высокий match (≥70%), отправленные отклики и полученные приглашения.
3. **Профиль резюме (Executive Resume Card):**
   * Выжимка ключевых навыков, выделенных AI из вашего резюме.
   * Кнопка «Редактировать текст резюме» прямо из браузера (обновляет `data/my_resume.txt`).
4. **Поисковая строка и фильтры:**
   * Поиск по **любой специальности или стеку** с кнопкой мгновенной очистки.
   * Быстрые пресеты (`Продуктовый аналитик`, `Системный аналитик`, `Data Analyst`, `Python Developer`, `Product Manager`).
   * **Фильтр регионов:** 🇷🇺 Вся Россия, 🏙️ Москва, 🏛️ Санкт-Петербург, Екатеринбург, Казань, Новосибирск, Минск, Алматы.
   * **Фильтр опыта:** 1–3 года, 3–6 лет, без опыта, более 6 лет.
5. **Карточки вакансий с детальным скорингом:**
   * **Score Badge:** наглядный % соответствия резюме.
   * **Краткое описание и требования:** сниппет ключевых обязанностей и задач.
   * **Детализация Match Score:**
     * 🟢 **Сильные стороны (Match):** теги совпавших технологий из вашего резюме.
     * 🔴 **Где слабее (Чего не хватает):** теги требуемых работодателем навыков, отсутствующих в резюме.
   * **Просмотр/редактирование письма:** редактирование сопроводительного письма перед отправкой.
   * **Кнопки действий:** «Откликнуться» (мгновенная отправка на HH) и «Пропустить».

## 📱 Управление через Telegram-бота

Бот оснащен удобным **постоянным кнопочным меню (Reply Keyboard)**, **интерактивной инлайн-панелью управления** и меню быстрых команд (`/`):

### 🔘 Кнопки нижнего меню:
* **`🔍 Поиск вакансий`** — выбор быстрых пресетов (`Python`, `Data Analyst`, `Product Manager`, `Системный аналитик`) или ввод любого вашего запроса текстом.
* **`🤖 AI-анализ базы`** — расчет Match Score % и генерация писем для всех новых вакансий.
* **`📊 Статистика`** — текущее состояние базы данных вакансий.
* **`📥 Скачать Excel`** — мгновенная отправка актуального файла `vacancies.xlsx` прямо в чат Telegram.
* **`📄 Мои резюме`** — просмотр всех ваших резюме на HH.ru и переключение активного одной кнопкой.
* **`⚙️ Настройки`** — интерактивная настройка региона (РФ / Москва / СПб), требуемого опыта и зарплатного фильтра.
* **`🔐 HH Авторизация`** — быстрая привязка аккаунта HeadHunter.
* **`❓ Помощь`** — справка и подсказки.

### 📋 Список команд в меню Telegram:
| Команда | Описание |
|---|---|
| `/start` | Главное меню, статус авторизации в HH и текущее резюме |
| `/menu` | Открыть интерактивную панель управления |
| `/search <запрос>` | Поиск по любой профессии (например: `/search Системный аналитик`, `/search Product Lead`) |
| `/analyze` | Запуск AI-скоринга и генерации писем |
| `/stats` | Сводка по базе: сколько вакансий `NEW`, `ANALYZED`, `APPLIED`, `INVITED`, `SKIPPED` |
| `/excel` | Скачать файл Excel прямо в Telegram |
| `/resumes` | Список ваших резюме на HeadHunter с инлайн-кнопками выбора активного |
| `/settings` | Меню фильтров и настроек поиска |
| `/auth` | Получение ссылки для авторизации нового аккаунта в HH.ru |
| `/code <код>` | Ввод кода авторизации HeadHunter прямо в чате |
| `/help` | Справка по использованию |

> **💡 Умный ввод:** вы можете просто написать боту название любой профессии в чат (например, *«Аналитик данных»* или *«Rust Developer»*), и бот предложит сразу найти по ней вакансии или сохранить как запрос по умолчанию.

### Интерактивные кнопки под карточками вакансий в Telegram:
* **`[🚀 Откликнуться]`** — мгновенный отклик с сопроводительным письмом + перевод статуса в `APPLIED`.
* **`[❌ Пропустить]`** — исключение вакансии + статус `SKIPPED`.
* **`[🔗 На сайт HH]`** — переход на страницу вакансии в браузере.

## 🔄 Смена аккаунта HH или резюме

1. **Смена аккаунта HeadHunter:**
   * Войдите на сайте [hh.ru](https://hh.ru) под новым пользователем.
   * Перейдите по ссылке из команды `/auth` (или `python main.py auth`) и нажмите «Разрешить».
   * Отправьте полученный код боту `/code <код>` или введите в терминале. Токены обновятся автоматически.
2. **Смена активного резюме:**
   * Отправьте команду `/resumes` в Telegram и нажмите кнопку **`[🎯 Использовать это резюме]`** на нужном резюме.
   * Либо выберите резюме в верхнем правом углу Web Dashboard.

## 🛠 Решение частых проблем (Troubleshooting)

### 1. Ошибка `client_id or client_secret not found`
* **Причина:** Неверно скопированы `Client ID` или `Client Secret` (например, перепутаны `0` и `O`, `1` и `I`).
* **Решение:** Откройте [dev.hh.ru/admin](https://dev.hh.ru/admin), скопируйте значения через кнопку 📋 и вставьте в `.env` в поля `HH_CLIENT_ID` и `HH_CLIENT_SECRET`.

### 2. Ошибка `code expired` или `code has already been used`
* **Причина:** Временный код авторизации действителен только 5 минут и может быть использован строго 1 раз.
* **Решение:** Заново перейдите по ссылке `/auth`, нажмите «Разрешить» и сразу передайте свежий код.

### 3. Ошибка `Не указан ID резюме (HH_RESUME_ID)`
* **Решение:** Вызовите команду `/resumes` в боте и нажмите кнопку выбора резюме, либо укажите `HH_RESUME_ID` в файле `.env`.

### 4. Ограничения HeadHunter API
* HeadHunter разрешает до 200 откликов в сутки на аккаунт. Рекомендуется откликаться на наиболее релевантные вакансии (Match Score ≥ 70%).
