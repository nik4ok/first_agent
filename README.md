# 🤖 AI Job Agent для HeadHunter

Универсальный автономный AI-агент для автоматизации поиска вакансий на **hh.ru**, глубокого скоринга резюме, генерации персонализированных сопроводительных писем, прохождения опросников и отправки откликов на автопилоте.

Управление осуществляется через **Web Dashboard** в браузере и интерактивного **Telegram-бота**.

## ✨ Возможности проекта

* 🔍 **Универсальный поиск вакансий**: сбор данных по любой специальности, ключевым словам, регионам РФ и СНГ, фильтрам опыта и зарплаты (гибридный клиент: официальный API + глубокий Web-скрапинг с выгрузкой полных описаний и требований).
* 🕒 **Умная сортировка по свежести**: фиксация точной даты/времени публикации вакансий с возможностью мгновенной сортировки:
  * 🕒 *Сначала свежие* (по времени публикации на HH);
  * 🎯 *По соответствию (Match Score)*;
  * 💰 *По зарплате (от максимальной)*;
  * 🏢 *По алфавиту компаний*.
* 📁 **Загрузка резюме в 1 клик**: поддержка файлов **PDF, DOCX, TXT** с автоматическим извлечением текста, выделением стека технологий и мгновенным пересчетом скоринга всей базы.
* 🧠 **AI-скоринг и сопроводительные письма**:
  * Расчет процента соответствия (**Match Score 0–100%**) на основе стека резюме и описания вакансии;
  * Детализация: 🟢 *Сильные стороны (Match)* и 🔴 *Где слабее (Чего не хватает)*;
  * Генерация живого персонального сопроводительного письма под стек работодателя (без шаблонных клише).
* 🚀 **Фоновые автоотклики через Playwright**:
  * Обход ограничений закрытого публичного API HeadHunter (ошибка 403 Forbidden);
  * Автоматический переход на страницу вакансии, прикрепление резюме, ввод письма и подтверждение отклика;
  * 🤖 **Автозаполнение тестов и опросников работодателя через AI**.
* 🛡️ **Безопасный Автопилот (Топ-отклики)**:
  * Автоматический отбор лучших вакансий (10, 25, 50 шт) с высоким Match Score (≥ 70%);
  * Отправка откликов с анти-спам задержкой (1.5–2 сек) для защиты от блокировок HeadHunter.
* 📊 **Локальная база данных в Excel (`data/vacancies.xlsx`)**:
  * Полная история вакансий, зарплат, статусов (`NEW`, `ANALYZED`, `APPLIED`, `INVITED`, `SKIPPED`), аналитических заметок и писем;
  * Автоматическая дедупликация (исключение повторного добавления).
* 🌐 **Web Dashboard в браузере (FastAPI + Tailwind CSS)**:
  * Полнофункциональный визуальный центр управления с KPI-метриками, фильтрами, карточками вакансий, редактором резюме и статусами авторизации.
* 📱 **Интерактивный Telegram-бот (`aiogram 3`)**:
  * Постоянное нижнее меню (Reply Keyboard), инлайн-панель управления, карточки вакансий с кнопками, команда `/autopilot` и отправка Excel прямо в чат.
* ⏰ **Фоновый планировщик (`APScheduler`)**:
  * Периодический автопоиск новых вакансий (каждые 30 мин) и трекинг статусов/приглашений от HR (каждые 10 мин).

## 🧠 Как работает AI-анализ и скоринг

AI-анализ в проекте функционирует в двух взаимодополняющих режимах:

### 1. Нейросетевой режим (при наличии `OPENAI_API_KEY` в `.env`)
* Модель выступает в роли Senior IT-рекрутера.
* В контекст передается полный текст резюме кандидата, название вакансии, описание обязанностей и ключевые навыки.
* Модель формирует объективный JSON-вердикт:
  * **Score** (0–100%) — общий процент соответствия;
  * **Matching Skills** — список совпавших технологий;
  * **Missing Skills** — критические навыки, которых нет в резюме;
  * **Pros & Cons** — сильные стороны и риски;
  * **Сопроводительное письмо** — авторский текст с акцентом на релевантный опыт кандидата под задачи команды.

### 2. Встроенный автономный AI-движок (работает без API-ключей)
* **Защита от чуждых профессий (Domain Guard):** мгновенное отсечение непрофильных сфер (общепит, транспорт, производство и т.д.) со снижением скора до 5% и фиксацией отсутствующих компетенций.
* **Семантический анализ роли (Role & Seniority Match):** определение соответствия специализации и грейда (Junior, Middle, Senior, Lead, Data Analyst, Python Dev, Product Manager).
* **Скан Hard Skills (100+ технологий):** автоматическое извлечение и сопоставление стека (`Python`, `SQL`, `PostgreSQL`, `FastAPI`, `Docker`, `Pandas`, `Tableau`, `Power BI`, `Kafka`, `ClickHouse`, `A/B-тестирование`, `Unit economics` и др.).
* **Формула Match Score:**
  $$\text{Match Score} = 0.35 \times \text{TitleMatch} + 0.50 \times \text{SkillsMatch} + 0.15 \times \text{DomainAlignment}$$

## 🚀 Быстрый старт с нуля

### Шаг 1. Настройка окружения и зависимостей

```bash
# Клонируйте проект или перейдите в его папку
cd first_agent

# Создайте и активируйте виртуальное окружение
python3 -m venv venv
source venv/bin/activate

# Установите все зависимости
pip install -r requirements.txt

# Установите браузер Playwright Chromium
playwright install chromium
```

---

### Шаг 2. Конфигурация `.env`

Создайте файл `.env` (или отредактируйте существующий):

```env
# HeadHunter API Keys (с портала dev.hh.ru/admin)
HH_CLIENT_ID=ВАШ_CLIENT_ID
HH_CLIENT_SECRET=ВАШ_CLIENT_SECRET
HH_REDIRECT_URI=https://hh.ru
HH_USER_AGENT=JobAgent/1.0 (ваш_email@gmail.com)

# ID вашего резюме на HeadHunter (из ссылки https://hh.ru/resume/XXXXXXXX)
HH_RESUME_ID=

# Telegram Bot (токен от @BotFather и ваш Chat ID от @userinfobot)
TELEGRAM_BOT_TOKEN=ВАШ_ТОКЕН_БОТА
TELEGRAM_CHAT_ID=ВАШ_ТЕЛЕГРАМ_CHAT_ID

# LLM (опционально: OpenAI, DeepSeek, Ollama, Groq)
OPENAI_API_KEY=
OPENAI_BASE_URL=
OPENAI_MODEL=gpt-4o
```

### Шаг 3. Загрузка резюме (PDF / DOCX / Текст)

Вы можете предоставить резюме любым удобным способом:
1. **Через Web Dashboard:** нажмите синюю кнопку **«📁 Загрузить файл (PDF/DOCX)»** в шапке дашборда и выберите файл резюме.
2. **Через текст:** нажмите кнопку **«Редактировать текст»** и вставьте описание вашего опыта.
3. **Напрямую в файл:** отредактируйте файл `data/my_resume.txt`.

*При любом обновлении резюме система автоматически пересчитает Match Score для всех вакансий в базе.*

### Шаг 4. Вход в аккаунт HeadHunter (Playwright + OAuth)

Для того чтобы бот мог автономно отправлять отклики и обходить блокировки API (ошибка 403 Forbidden):

1. **Вход в браузере (Выполняется 1 раз):**
   * Откройте Web Dashboard (`http://localhost:8000`).
   * В правом верхнем углу нажмите кнопку **«🔐 Вход в браузере»**.
   * Нажмите **«1. Открыть окно входа на HH.ru»** (откроется окно браузера).
   * Войдите в свой аккаунт HeadHunter (по СМС, паролю, почте или Госуслугам/Сбер ID).
   * Нажмите **«2. Сохранить сессию»**. Статус сменится на **`🟢 Браузер готов`**.
   *(Либо выполните команду в терминале: `./venv/bin/python main.py browser-login`)*.

2. **Привязка OAuth (опционально для чтения профиля):**
   * Нажмите кнопку **«HH Ready»** в шапке дашборда или выполните `./venv/bin/python main.py auth`.

## 🛠 Решение частых проблем (Troubleshooting)

### 1. Ошибка запуска браузера `Executable doesn't exist`
* **Причина:** Не установлены бинарные файлы браузера Chromium для Playwright.
* **Решение:** Выполните в терминале:
  ```bash
  ./venv/bin/playwright install chromium
  ```
  *(В проект также встроен автоматический fallback на установленный в системе Google Chrome).*

### 2. Ошибка отклика `403 Forbidden: type: forbidden`
* **Причина:** HeadHunter заблокировал отправку откликов соискателей через публичный REST API.
* **Решение:** Используйте встроенный браузерный движок Playwright. Для этого нажмите кнопку **«🔐 Вход в браузере»** в шапке дашборда (или выполните `python main.py browser-login`) и сохраните сессию.

### 3. Ошибка `TelegramNetworkError / ClientConnectorDNSError`
* **Причина:** Блокировка доступа к `api.telegram.org` со стороны провайдера или отсутствие VPN.
* **Решение:** 
  * Включите VPN, либо укажите локальный прокси в `.env` (например, `TELEGRAM_PROXY=socks5://127.0.0.1:10808` или `http://127.0.0.1:7890`);
  * Даже без Telegram веб-дашборд (`http://localhost:8000`) и планировщик продолжают работать в полном объеме.

### 4. Ошибка `client_id or client_secret not found`
* **Причина:** Опечатка при копировании ключей с портала разработчиков.
* **Решение:** Перейдите на [dev.hh.ru/admin](https://dev.hh.ru/admin), скопируйте `Client ID` и `Client Secret` и вставьте в `.env`.
