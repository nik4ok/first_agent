# 🤖 AI Job Agent для HeadHunter

Локальный агент для поиска работы на **hh.ru**: парсит вакансии (Россия, СНГ и весь мир, в том числе `ex_ru` — мир без РФ), сравнивает их с вашим резюме, считает Match Score, пишет сопроводительные письма и отправляет отклики через браузер Playwright.

Управляется из **Web Dashboard** (`http://localhost:8000`) и **Telegram-бота**. Нейросеть не обязательна: без API-ключа работают локальный скоринг, аудит резюме и автопилот. Отклики считаются отправленными только после подтверждения HH («Вы откликнулись») и пишутся в журнал `data/sent_applications.json`, а не только в Excel.

## ✨ Возможности проекта

* 🔍 **Универсальный и гибкий поиск вакансий**:
  * Сбор данных по любой специальности и стеку;
  * **Парсинг любого объема вакансий**: выбор от 10 до 500+ вакансий с автоматической пагинацией;
  * **Фильтрация по свежести публикации (`SEARCH_PERIOD`)**: За последние 24 часа (1 день), 3 дня, 1 неделю, 2 недели, 1 месяц, 2 месяца, 3 месяца, 1 год или за все время;
  * **Настраиваемый опыт работы (`SEARCH_EXPERIENCE`)**: Любой опыт (`all`), Без опыта (`noExperience`), 1–3 года (`between1And3`), 3–6 лет (`between3And6`), Более 6 лет (`moreThan6`);
  * **Настраиваемая сортировка**: По дате/свежести (`publication_time`) или По соответствию (`relevance`);
  * **Фильтры по регионам (`SEARCH_AREA`)**: весь мир (`all`), весь мир кроме России (`ex_ru`), Вся Россия (`113`), Москва, СПб, Казань, Екатеринбург и др. Режим `ex_ru` ищет по СНГ и зоне HH «Другие регионы» (ЕС, Кипр, remote, вакансии в USD/EUR).
* 📊 **Анализ рынка и аудит компетенций резюме (Market & ATS Audit)**:
  * Анализ частотного рейтинга топ-15 навыков работодателей на всем спарсенном срезе рынка в выбранной сфере;
  * Расчет **Индекса конкурентоспособности резюме (0–100%)**;
  * Выделение ваших сильных сторон (🟢 Match) и критичных пробелов рынка (🔴 Gaps);
  * Практические рекомендации по оцифровке опыта и добавлению ключевых слов для прохождения ATS-фильтров.
* 📁 **Загрузка резюме в 1 клик**: поддержка файлов **PDF, DOCX, TXT**, прямой вставки текста или синхронизации с аккаунтом HeadHunter.
* 🧠 **AI-скоринг и сопроводительные письма**:
  * Расчет процента соответствия (**Match Score 0–100%**) на основе стека резюме и описания вакансии;
  * Детализация: 🟢 *Сильные стороны (Match)* и 🔴 *Где слабее (Чего не хватает)*;
  * Генерация живого персонального сопроводительного письма под стек работодателя (без шаблонных клише).
* 🚀 **Фоновые автоотклики через Playwright**:
  * Обход закрытого публичного API HeadHunter (403 Forbidden);
  * Модальные окна и 1-клик отклики; подтверждение вакансий в другой стране («Всё равно откликнуться»);
  * Письмо вставляется в форму отклика и **не затирается** полями анкеты работодателя;
  * Статус «Вы откликнулись» проверяется после перезагрузки страницы — ложных APPLIED в журнал не пишем.
* 🛡️ **Автопилот с очередью и подтверждением**:
  * Режимы: просмотр письма перед отправкой (`review`) или автомат без подтверждения (`auto`);
  * Отбор по Match Score, ключевым словам и лимиту (10 / 25 / 50 / 100);
  * Растягивание пачки на 30 мин – 6 часов (тикер раз в ~15 сек), чтобы не словить антибот HH;
  * Статус `QUEUED` в Excel, пока вакансия в очереди.
* 📊 **Локальная база Excel + журнал откликов**:
  * `data/vacancies.xlsx` — вакансии, скоры, письма, статусы `NEW` / `ANALYZED` / `QUEUED` / `APPLIED` / `INVITED` / `SKIPPED`;
  * Файловые локи, чтобы веб, бот и автопилот не портили xlsx одновременно;
  * `data/sent_applications.json` (+ `.xlsx`) — канон реально ушедших откликов; KPI «Отправлено» берётся отсюда;
  * 🗑️ Очистка базы в 1 клик через дашборд или `/clear` в Telegram.
* 🌐 **Web Dashboard в браузере (FastAPI + Tailwind CSS)**:
  * Чистый и понятный интерфейс из 5 ключевых блоков;
  * Живые KPI-метрики: Всего в базе, Отправлено откликов, Высокий Match (≥70%), Средний скор релевантности.
* 📱 **Интерактивный Telegram-бот (`aiogram 3`)**:
  * Меню управления, карточки вакансий, команда `/autopilot`, команда `/audit` (аудит резюме прямо в чате) и отправка Excel файла.

## 🧠 Как работает AI-анализ и скоринг

AI-анализ в проекте функционирует в двух взаимодополняющих режимах:

### 1. Нейросетевой режим (при наличии `OPENAI_API_KEY` в `.env`)
* Модель выступает в роли Senior IT-рекрутера.
* В контекст передается полный текст резюме кандидата, название вакансии, описание обязанностей и ключевые навыки.
* Модель формирует объективный JSON-вердикт:
  * **Score** (0–100%) — общий процент соответствия;
  * **Matching Skills** — список совпавших технологий;
  * **Missing Skills** — критические навыки, которых нет в резюме;
  * **Pros & Cons** — сильные стороны и риски;
  * **Сопроводительное письмо** — авторский текст с акцентом на релевантный опыт кандидата под задачи команды.

### 2. Встроенный автономный AI-движок (работает без API-ключей)
* **Защита от чуждых профессий (Domain Guard):** мгновенное отсечение непрофильных сфер (общепит, транспорт, производство и т.д.) со снижением скора до 5% и фиксацией отсутствующих компетенций.
* **Семантический анализ роли (Role & Seniority Match):** определение соответствия специализации и грейда (Junior, Middle, Senior, Lead, Data Analyst, Python Dev, Product Manager).
* **Скан Hard Skills (100+ технологий):** автоматическое извлечение и сопоставление стека (`Python`, `SQL`, `PostgreSQL`, `FastAPI`, `Docker`, `Pandas`, `Tableau`, `Power BI`, `Kafka`, `ClickHouse`, `A/B-тестирование`, `Unit economics` и др.).
* **Формула Match Score:**
  $$\text{Match Score} = 0.35 \times \text{TitleMatch} + 0.50 \times \text{SkillsMatch} + 0.15 \times \text{DomainAlignment}$$

## 🚀 Быстрый старт с нуля

### Шаг 1. Настройка окружения и зависимостей

```bash
# Клонируйте проект или перейдите в его папку
cd first_agent

# Создайте и активируйте виртуальное окружение
python3 -m venv venv
source venv/bin/activate

# Установите все зависимости
pip install -r requirements.txt

# Установите браузер Playwright Chromium
playwright install chromium
```

### Шаг 2. Конфигурация `.env`

Создайте файл `.env` (или отредактируйте существующий):

```env
# HeadHunter API Keys (с портала dev.hh.ru/admin)
HH_CLIENT_ID=ВАШ_CLIENT_ID
HH_CLIENT_SECRET=ВАШ_CLIENT_SECRET
HH_REDIRECT_URI=https://hh.ru
HH_USER_AGENT=JobAgent/1.0 (ваш_email@gmail.com)

# ID вашего резюме на HeadHunter (из ссылки https://hh.ru/resume/XXXXXXXX)
HH_RESUME_ID=

# Поиск (по умолчанию; те же фильтры можно менять в дашборде и Telegram)
SEARCH_TEXT=Продуктовый аналитик
SEARCH_AREA=113
# all — весь мир, ex_ru — весь мир кроме России, 113 — РФ, 1 — Москва, 2 — СПб
SEARCH_EXPERIENCE=between3And6
SEARCH_PERIOD=30
SEARCH_ONLY_WITH_SALARY=false

# Telegram Bot (токен от @BotFather и ваш Chat ID от @userinfobot)
TELEGRAM_BOT_TOKEN=ВАШ_ТОКЕН_БОТА
TELEGRAM_CHAT_ID=ВАШ_ТЕЛЕГРАМ_CHAT_ID

# LLM (опционально: OpenAI, DeepSeek, Groq, Ollama). Без ключа работает локальный скоринг.
OPENAI_API_KEY=
OPENAI_BASE_URL=
OPENAI_MODEL=gpt-4o
```

### Шаг 3. Загрузка резюме (PDF / DOCX / Текст)

Вы можете предоставить резюме любым удобным способом:
1. **Через Web Dashboard:** нажмите синюю кнопку **«📁 Загрузить файл (PDF/DOCX)»** в шапке дашборда и выберите файл резюме.
2. **Через текст:** нажмите кнопку **«Редактировать текст»** и вставьте описание вашего опыта.
3. **Напрямую в файл:** отредактируйте файл `data/my_resume.txt`.

*При любом обновлении резюме система автоматически пересчитает Match Score для всех вакансий в базе.*

### Шаг 4. Вход в аккаунт HeadHunter (Playwright + OAuth)

Для того чтобы бот мог автономно отправлять отклики и обходить блокировки API (ошибка 403 Forbidden):

1. **Вход в браузере (Выполняется 1 раз):**
   * Откройте Web Dashboard (`http://localhost:8000`).
   * В правом верхнем углу нажмите кнопку **«🔐 Вход в браузере»**.
   * Нажмите **«1. Открыть окно входа на HH.ru»** (откроется окно браузера).
   * Войдите в свой аккаунт HeadHunter (по СМС, паролю, почте или Госуслугам/Сбер ID).
   * Нажмите **«2. Сохранить сессию»**. Статус сменится на **`🟢 Браузер готов`**.
   *(Либо выполните команду в терминале: `./venv/bin/python main.py browser-login`)*.

2. **Привязка OAuth (опционально для чтения профиля):**
   * Нажмите кнопку **«HH Ready»** в шапке дашборда или выполните `./venv/bin/python main.py auth`.

## 🚀 Автопилот: очередь откликов без таймаута HTTP

HTTP-запрос только **ставит очередь** в `data/autopilot_state.json` и сразу возвращается. Дальше тикер (FastAPI lifespan / APScheduler, ~15 сек) отправляет по одной вакансии, когда наступило `next_at`. Так 50 откликов можно растянуть на 3 часа, не роняя дашборд и не паля HH пачкой запросов.

1. **Web Dashboard:** кнопка **«🚀 Автопилот (Топ-отклики)»**.
   * **Режим:** «С подтверждением письма» (по умолчанию: карточка → отправить / поправить / пропустить) или «Автомат, без подтверждения».
   * **Критерии:** ключевые слова через запятую (все фрагменты должны встретиться в title/компании/описании).
   * **Порог Match Score**, число вакансий, окно «растянуть на» (30 мин … 6 ч, либо «быстро» с паузой ~90 сек).
2. **Telegram:** `/autopilot 50` или кнопка **«🚀 Автопилот»** — те же режимы и интервал.
3. **Что происходит:**
   * Свободные вакансии (не `APPLIED` / `SKIPPED` / `INVITED` / `QUEUED`) сортируются по скору;
   * Письмо берётся из Excel, если оно не шаблонное; иначе генерируется из **текущего** `my_resume.txt`;
   * Playwright кликает «Откликнуться», подтверждает другую страну, вставляет письмо, не затирает его анкетой;
   * Успех только если HH показал «Вы откликнулись» — запись в `sent_applications.json` и статус `APPLIED`.

## 💻 Консольные команды (CLI)

```bash
# 1. Вход в аккаунт HeadHunter через браузер Playwright (для автооткликов)
./venv/bin/python main.py browser-login

# 2. Собрать вакансии в Excel
./venv/bin/python main.py parse --query "Data Analyst" --count 20 --area 113
# Весь мир кроме России (СНГ + ЕС/remote):
./venv/bin/python main.py parse --query "product analyst remote" --count 50 --area ex_ru

# 3. Запустить AI-скоринг и генерацию писем для всех новых вакансий
./venv/bin/python main.py analyze

# 4. Пройти OAuth-авторизацию HeadHunter
./venv/bin/python main.py auth
```

## 🛠 Решение частых проблем (Troubleshooting)

### 1. Ошибка запуска браузера `Executable doesn't exist`
* **Причина:** Не установлены бинарные файлы браузера Chromium для Playwright.
* **Решение:** Выполните в терминале:
  ```bash
  ./venv/bin/playwright install chromium
  ```
  *(В проект также встроен автоматический fallback на установленный в системе Google Chrome).*

### 2. Ошибка отклика `403 Forbidden: type: forbidden`
* **Причина:** HeadHunter заблокировал отправку откликов соискателей через публичный REST API.
* **Решение:** Используйте встроенный браузерный движок Playwright. Для этого нажмите кнопку **«🔐 Вход в браузере»** в шапке дашборда (или выполните `python main.py browser-login`) и сохраните сессию.

### 3. Ошибка `TelegramNetworkError / ClientConnectorDNSError`
* **Причина:** Блокировка доступа к `api.telegram.org` со стороны провайдера или отсутствие VPN.
* **Решение:** 
  * Включите VPN, либо укажите локальный прокси в `.env` (например, `TELEGRAM_PROXY=socks5://127.0.0.1:10808` или `http://127.0.0.1:7890`);
  * Даже без Telegram веб-дашборд (`http://localhost:8000`) и планировщик продолжают работать в полном объеме.

### 4. Ошибка `client_id or client_secret not found`
* **Причина:** Опечатка при копировании ключей с портала разработчиков.
* **Решение:** Перейдите на [dev.hh.ru/admin](https://dev.hh.ru/admin), скопируйте `Client ID` и `Client Secret` и вставьте в `.env`.

### 5. В чат работодателю ушла короткая заглушка вместо письма
* **Причина (исправлено в текущей версии):** анкета HH заполняла все `textarea`, в том числе поле сопроводительного.
* **Решение:** обновите код; письмо восстанавливается после опросника. Уже ушедшие заглушки можно дописать вручную в чате вакансии (текст лежит в Excel / журнале откликов).

### 6. Отклик на зарубежную вакансию не подтверждается
* **Причина:** HH показывает «Всё равно откликнуться», резюме скрыто, либо доп. анкета профиля.
* **Решение:** включите видимость резюме на hh.ru, сохраните сессию браузера заново. Автопилот не помечает APPLIED, пока на странице нет «Вы откликнулись».
