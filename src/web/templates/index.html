Вход на HH.ru для автооткликов

Playwright эмуляция браузера (обход закрытого API HeadHunter)

Почему необходим вход в браузере:

HeadHunter отключил отправку откликов соискателей через публичный API (ошибка 403 Forbidden). Чтобы бот мог автоматически откликаться и отправлять письма на автопилоте, он использует защищенный браузер с вашей сохраненной сессией.

1️⃣ Шаг: Открыть окно браузера

Нажмите кнопку ниже. Откроется окно браузера Chrome. Войдите в свой аккаунт HeadHunter (по СМС, почте, паролю или Госуслугам/Сбер ID).

2️⃣ Шаг: Сохранить сессию

После того как вы вошли в свой профиль на сайте hh.ru, нажмите «Сохранить сессию». Браузер закроется, а сессия сохранится навсегда.
